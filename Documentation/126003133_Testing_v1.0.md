# Testing

```powershell
cd Code\autosar_hld_assistant
python -m pytest -v
```

The tests also run from the parent folder (`python -m pytest autosar_hld_assistant/tests`).
`conftest.py` sets up the import path, points data storage at a temporary folder, and blanks every
LLM credential, so the tests never touch `data/` and never call a real API.
